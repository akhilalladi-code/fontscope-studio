Privacy notice

FontScope is designed to inspect fonts locally. This notice explains what happens when you use the browser application.

Effective date: 16 November 2026

Font files and processing

Font files you select are read by your browser and parsed locally using a Web Worker. Font bytes are held in browser memory for the active page session. FontScope does not provide a font-upload endpoint or send imported font files to an application server.

Refreshing or closing the page clears the application's in-memory font data. Files you explicitly download or save remain under your control.

Installed-font permission

If you choose “Scan my installed fonts” in a supported browser, the browser may ask you to grant Local Font Access permission. If granted, FontScope receives font metadata such as family, full name, PostScript name and style so it can display and filter the results. FontScope does not read or upload the installed font file contents through this feature.

You can clear the displayed results in the application or revoke the permission using your browser's site settings.

Analytics, accounts and cookies

The current application does not require an account, does not use an application database, and does not include an analytics or advertising integration. FontScope does not intentionally set application cookies.

GitHub Pages hosts the static website. GitHub may process technical request information under its own policies and infrastructure practices.

Third-party links

The application may link to GitHub for source code, issues and project information. When you follow an external link, that provider's privacy practices apply.

Security and limitations

Local processing reduces the need to transmit font files, but it does not remove risks from a compromised device, browser, browser extension or downloaded file. Keep your browser updated and only open font files from sources you trust.

FontScope's Unicode coverage and metadata checks are advisory. They are not legal, licensing or complete typographic validation services.

Contact

For questions or privacy-related requests, use the FontScope GitHub issue tracker. Do not include font files or private information in a public issue.
